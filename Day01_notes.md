## Client : who sends request to the server to perform some operations or to send response
* can be a WEB APP
* can be a MOBILE APP
* can be a DESKTOP APP
* can be an another SERVER
<hr>


## Request : message send by client to the server ask to perform some operation or provide a resource.
<br>

## HTTP Method : the set of rules to communicate between the client and the server.
* GET : Retrieve or read  R
* POST : Create   C
* PUT : Replace or update  U
* PATCH : Update partially U
* DELETE : Remove  D
<hr>
<br>

## Server : the software which receives requests and processes them.
<br>

## Response : A message sent by the server back to the client containing the result of processing the request.
<br>

## Status Code 
* 200 : OK successfully
* 201 : Created Successfully
* 400 : Bad Request
* 401 : unauthorised ( Client is not Authenticated) Who are you?
* 403 : forbidden ( Client is Authenticated but not Authorised does not have permisssion to perform that action.)
* 404 : not Found 
* 500 : Internal Server Error
